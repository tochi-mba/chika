install

pick your platform. each installer registers in your OS app manager so you can uninstall like a normal app.

Windows

Windows 10/11 · per-user install · no admin
chika-setup.exe

uninstall via Settings → Apps → Installed apps → Chika

macOS

macOS 12+ · pkg installer · admin required
Chika.pkg

uninstall via sudo /Library/Application\ Support/Chika/uninstall.sh

Linux .deb

debian/ubuntu/mint/pop!_os
chika_all.deb

uninstall via sudo apt remove chika

Linux universal

any distro with bash + curl
curl -fsSL https://raw.githubusercontent.com/tochi-mba/chika/main/installers/linux/install.sh | bash

uninstall via ~/.local/share/chika/uninstall.sh

from source

python 3.11+ required
git clone https://github.com/tochi-mba/chika.git && cd chika && python install.py

uninstall via chika uninstall

PyPI

coming soon
pip install chika

standard pip install when released

update

chika updates itself on launch when upstream CI is green. you don't need to do anything. but if you want to:

from the CLI

chika update
chika update --check
chika doctor

from inside the REPL

/update
/update --check
/auto-update on|off
/doctor

auto-update only applies on a fast-forward to main with all CI green and your working tree clean. never rolls you onto a broken commit.

uninstall

two ways: the os app manager (the one you already know), or chika uninstall.

OS app manager

  • Windows: Settings → Apps → Installed apps → Chika
  • macOS: sudo /Library/Application\ Support/Chika/uninstall.sh
  • Linux (deb): sudo apt remove chika
  • Linux (universal): ~/.local/share/chika/uninstall.sh

CLI

chika uninstall
chika uninstall --yes
chika uninstall --remove-data

user data at ~/.chika/ is preserved by default. delete it manually if you want a clean removal.
